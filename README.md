# Decorator Pattern — Burger Ordering System

A PHP 8.1+ implementation of the Decorator design pattern, using a burger-ordering
scenario where toppings (Cheese, Bacon, Sauce) are added dynamically to a base burger
without subclassing every combination.

## Requirements
- PHP 8.1 or higher
